## 公開方法
1. GitHubで `developer-portfolio` というPublicリポジトリを作成します。
2. ZIP内の全ファイルをリポジトリ直下へアップロードします。
3. Settings → Pagesを開きます。
4. SourceをDeploy from a branch、Branchをmain、Folderを/(root)に設定します。
5. 数分後に `https://kentaro0810.github.io/developer-portfolio/` で公開されます。
